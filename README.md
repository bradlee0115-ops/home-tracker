# 우리집 후보 실거래 기록

관심 단지(40곳)의 **국토교통부 실거래**를 매일 아침 7시에 자동으로 모아 웹사이트로 보여줍니다.
GitHub Actions가 데이터를 받고, GitHub Pages가 사이트를 띄웁니다. PC를 켜둘 필요가 없습니다.

사이트에서 볼 수 있는 것
- **새로 신고된 거래**: 관심 단지에 새로 공개된 실거래 (최근 7일)
- **관심 단지 표**: 단지별 최근 실거래, 3개월 거래 수, 엑셀 호가. 행을 누르면 가격 추이 차트
- **동별 흐름**: 사당·신대방·상도·신길·마곡동의 거래 수와 평당가 변화(최근 90일 vs 직전 90일)
- **구별 주간 아파트값**: 한국부동산원 주간 지수 (선택 설정)

## 1. 저장소 만들기
1. GitHub에서 새 저장소를 만듭니다 (예: `home-tracker`).
   - **Public**이면 무료로 Pages를 쓸 수 있습니다. 실거래는 공공데이터라 공개돼도 문제는 없지만, 관심 단지 목록이 공개된다는 점은 감안하세요. Private 저장소의 Pages는 유료 요금제가 필요합니다.
2. 이 폴더의 파일을 모두 올립니다 (`.github` 폴더 포함).

## 2. 실거래 API 키 받기 (필수)
1. 공공데이터포털(data.go.kr)에서 **국토교통부_아파트 매매 실거래가 상세 자료**를 검색해 활용 신청합니다. 보통 바로 승인되지만, 실제 호출이 되기까지 1~2시간 걸릴 수 있습니다.
2. 마이페이지에서 **일반 인증키(Decoding)**를 복사합니다.
3. 저장소 **Settings → Secrets and variables → Actions → New repository secret**
   - 이름: `MOLIT_API_KEY`, 값: 복사한 키

> API 주소는 `scripts/update.py`의 `MOLIT_URL`에 있습니다. 공공데이터포털 안내 페이지의 요청 주소와 다르면 이 값만 바꾸세요.

## 3. 사이트 켜기
1. **Settings → Pages → Build and deployment**
   - Source: `Deploy from a branch`
   - Branch: `main`, 폴더: `/docs` → Save
2. 몇 분 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 열립니다.

## 4. 첫 데이터 받기
1. **Actions 탭 → Update data → Run workflow**를 누릅니다.
2. 1~3분 뒤 초록 체크가 뜨면 사이트를 새로고침하세요.
3. 이후 매일 07시(한국시간)에 자동 실행됩니다. 첫 실행 다음 날부터 '새로 신고된 거래'가 채워집니다.

## 5. 단지 이름 맞추기 (처음 한 번)
국토부 데이터의 단지명은 네이버와 다를 수 있습니다 (예: `극동` ↔ `이수극동`).
사이트 맨 아래 **'연결 안 된 단지명 보기'**에서 관심 단지가 보이면,
`config/complexes.json`에서 해당 단지의 `aliases`에 그 이름을 추가하고 커밋하세요. 다음 실행부터 연결됩니다.

## 6. 주간 동향 켜기 (선택)
한국부동산원 부동산통계정보시스템(R-ONE)에서 오픈API 키를 발급받고,
**주간 아파트 매매가격지수(시군구)** 통계표 ID를 확인해 Secrets에 등록합니다.
- `REB_API_KEY`: 인증키
- `REB_STATBL_ID`: 통계표 ID

> R-ONE 오픈API의 요청 주소·응답 형식은 제작 시점에 직접 검증하지 못했습니다. 사이트에 '주간 동향 수집 실패'가 뜨면 R-ONE 안내 문서를 보고 `scripts/update.py`의 `REB_URL`과 `update_weekly()`를 맞춰 주세요. 이 기능이 실패해도 실거래 기능은 그대로 동작합니다.

## 관심 단지 바꾸기
`config/complexes.json`을 고치면 됩니다. 단지를 추가할 때는 `lawd`(시군구 코드: 동작구 11590, 영등포구 11560, 강서구 11500, 서초구 11650)와 `dong`(법정동 이름)을 함께 적어야 합니다.

## 알아둘 점
- 실거래는 **계약 후 30일 안에 신고**되므로 최근 거래는 며칠~몇 주 늦게 보입니다. 호가가 아니라 실제 체결 가격입니다.
- 해제(취소)된 거래는 취소선으로 표시하고, 통계에서는 뺍니다.
- 네이버부동산 호가는 공식 API가 없어 포함하지 않았습니다.
